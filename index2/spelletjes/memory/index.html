Memory

Probeer de positie van de 12 kaarten te onthouden en als ze verdwijnen probeer de 6 combinaties te vinden voor de tijd op is. Makkelijk in het begin, maar je hebt een goed geheugen nodig in de latere levels.

Try to remember the positions of the 12 cards, and when they disappear try to find the 6 combinations before time runs out. Very easy to start with but it requires a very good memory at the later levels.
